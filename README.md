# Decision Tree Classifier - Bank Marketing Dataset

## Objective
Build a Decision Tree Classifier to predict whether a customer will purchase a product/service based on demographic and behavioral data.

## Dataset
Bank Marketing Dataset from UCI Machine Learning Repository.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Workflow
1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis
4. Label Encoding
5. Train-Test Split
6. Decision Tree Model Building
7. Model Evaluation
8. Visualization

## Results
📌 Most customers did not subscribe to the product/service, showing class imbalance in the dataset.
📌 Customers in middle age groups showed a higher likelihood of purchasing the service compared to younger customers.
📌 Customers with stable professions such as management and technician roles had higher subscription rates.
📌 Customers with higher account balances were more likely to subscribe to the product/service.
📌 Feature importance analysis revealed that duration, balance, and age were among the strongest predictors in customer purchasing behavior.
